THE SIX MICRO-FIXES
====================================================================

1. D4-012  option C broadened claim narrowed to match its explanation.
   "That synthetic records reproduce the relationships present in the
   real data"
   ->
   "That synthetic records preserve the relationships and variation
   relevant to the prediction task"
   Explanation C unchanged. Key C unchanged.

2. D4-020  explanation B no longer claims precision determines
   inspection effort, which also depends on flagged volume.
   Now: precision directly answers how often a flagged part proves
   faulty, and COMBINED WITH FLAGGED VOLUME can help quantify
   inspection effort spent on sound parts.
   Stem, options and key B unchanged.

3. D4-021  explanation B no longer teaches the overbroad rule that
   "data quality work happens before splitting and applies to the whole
   dataset" - some preprocessing must be fitted on training data only.
   Now: checking data quality is a separate purpose from the roles of
   the validation and test sets; the validation set guides development
   choices while the untouched test set provides the final independent
   estimate. Key A unchanged.

4. D4-027  keyed option C now states the temporal defect the stem
   establishes, instead of assuming a prior risk judgement.
   "The field may reflect churn risk already identified rather than
   predicting it"
   ->
   "The field is created after the intended scoring point, so it will
   not be available with the same meaning"
   Key idea and explanation C already carried this principle and were
   left as they were. Key C unchanged.

5. D4-040  absolute wording removed from the keyed option and the key
   idea, matching the explanation, which already said "may apply".
   option A  "The model will be applied outside the conditions it was
   evaluated for" -> "The model may be applied outside the conditions
   it was evaluated for"
   key idea  "a model gets applied" -> "a model may be applied"
   Key A unchanged.

6. D4-047  explanation A no longer depends on a class distribution the
   stem does not establish.
   Now: overall accuracy counts correct classifications rather than the
   monetary value of missed incorrect invoices or the review workload
   created by flagged invoices, so it does not directly measure either
   stakeholder concern.
   Nothing else in D4-047 was touched. Keys C,E unchanged.
