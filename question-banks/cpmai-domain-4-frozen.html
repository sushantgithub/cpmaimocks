CPMAI-D4-001 Feature engineering and preparationHARD Answer: A

A team proposes deriving a customer tenure feature for a churn model by subtracting each customer's signup date from today's date, recomputed automatically every time the model runs in production. What should the project manager check?

  1. AThat tenure is measured as of the prediction point in training records and at production scoring time
  2. BThat signup dates are stored in a date type rather than as text strings
  3. CThat the tenure feature is expressed in days rather than in months
  4. DThat customers with no recorded signup date are excluded from the dataset before training begins
Key ideaTenure must be measured as of the prediction point, both in historical training records and at scoring time.
AIn training, tenure should be measured as of the moment each historical outcome occurred; in production it is measured at the point of scoring. If the historical records are instead computed against today's date, the feature carries a different meaning in each setting and the learned relationship no longer holds.
BDate typing prevents parsing errors and is worth confirming. It is a data hygiene point rather than the semantic trap in this derivation.
CDays or months is a granularity choice with little consequence, since one converts to the other. It does not affect correctness.
DHandling customers with no signup date is a necessary decision either way. It is a completeness question separate from the reference-point issue.
CPMAI-D4-002 Model evaluation metricsEASY Answer: B

A team reports a model at ninety-one per cent accuracy, measured on the records it was trained on. The team has not scored the model on any data it did not see during training, and proposes to put the figure to the steering group as evidence of the performance expected once the model is in use. What should the project manager require?

  1. AThat the figure be reported with a note explaining it was measured on the training records
  2. BA score on held-out data before that claim is put to the steering group
  3. CThat the team retrain the model until training accuracy reaches at least ninety-five per cent
  4. DThat precision and recall be calculated alongside accuracy on the same training records
Key ideaPerformance measured on training records shows what a model retained, not what it will do on new cases.
ALabelling the figure correctly is honest and worth doing. It does not turn a training score into evidence of how the model will perform in use, which is the claim being made.
BA model can reproduce its training records closely and still fail on new ones. Only a score on data held back from training supports a claim about expected performance in use.
CPushing training accuracy higher moves in the wrong direction, since it can indicate the model is fitting the training records ever more closely.
DAdditional measures on the same records share the same defect. They describe the training data rather than future performance.
CPMAI-D4-003 Training data strategy and validation designMEDIUM Answer: C

A team is splitting data for a classifier in which one outcome accounts for about three per cent of records. A random split leaves the test set with very few examples of that outcome, and the measured performance on it varies substantially between runs. The dataset is large enough that preserving the three per cent proportion would place an adequate number of those records in the test set. What splitting approach should the project manager expect?

  1. AA larger test set, so that the rare outcome appears in it often enough to be measured reliably
  2. BRemoval of the rare outcome from the test set, so the measured score is not distorted by so few cases
  3. CA stratified split, preserving the proportion of each outcome in every set
  4. DDuplication of the rare records until they make up an equal share of the test set
Key ideaPreserving each class's proportion in every split stops the rare outcome's test count being left to chance.
AEnlarging the test set does raise the count of rare cases, but it takes records away from training and still leaves their number to chance. Stratification addresses the cause directly.
BExcluding the rare outcome removes exactly the behaviour most in need of evaluation. The resulting score would describe only the common case.
CStratification places the same three per cent share in each split. On a dataset of the size the stem describes, that yields a consistent and adequate number of rare cases rather than leaving the count to the draw.
DDuplicating test records inflates the apparent sample without adding evidence, and makes the score depend repeatedly on the same few cases.
CPMAI-D4-004 Bias, fairness and evaluation transparencyHARD Answer: B

A team is asked to make a screening model fair across two applicant groups. It finds that equalising the share of qualified applicants accepted in each group, and equalising the share of accepted applicants who prove qualified, cannot both be achieved given the different base rates. The team asks the project manager how to proceed.

  1. AChoose whichever definition the model satisfies more closely as it currently stands
  2. BDecide with the stakeholders which definition applies here, and record the reasoning
  3. CReport both measures without selecting between them, so stakeholders can see the full position
  4. DAdjust the data until the base rates in the two groups match, so both definitions can hold
Key ideaDifferent fairness definitions can be mutually unattainable, so the choice must be made deliberately.
AThis lets the model's present behaviour set the standard, which reverses the order. The standard should be chosen first and the model measured against it.
BWhen the definitions cannot hold together, the choice is about which harm matters more in this setting. That is a decision for accountable stakeholders, documented so it can be reviewed.
CTransparent reporting is necessary and should happen regardless. It does not discharge the obligation to decide which standard the model must meet.
DAltering the data to remove a real difference misrepresents the population, and the model would be tuned to a situation that does not exist.
CPMAI-D4-005 Experiment management and iteration governanceHARD Answer: A

A team has spent three months on model experiments. Performance improved substantially in the first month, marginally in the second and not at all in the third. The team requests two further months, arguing that a breakthrough is still possible. What should the project manager weigh?

  1. AWhether the current model is good enough to be useful, against the cost of continuing
  2. BWhether the team has tried every algorithm that could plausibly suit this problem
  3. CWhether two months matches the time already spent, so the investment is balanced
  4. DWhether the sponsor is willing to fund two further months of the team's time
Key ideaA flattening improvement curve is evidence about expected return, and a stopping rule should reflect it.
AThe pattern of gains suggests further effort will return little. The decision turns on whether what exists now delivers value, not on whether a breakthrough remains conceivable.
BExhausting the options is not a stopping rule, since the list is effectively open-ended. It would justify indefinite continuation.
CTime already spent is not recoverable and should not shape the decision. Only the expected return on further effort is relevant.
DWillingness to fund is necessary to proceed but does not establish that proceeding is worthwhile.
CPMAI-D4-006 Model approach and algorithm selectionMEDIUM Answer: D

A team must classify incoming support tickets into a small set of categories. One member proposes adapting a general-purpose language model; another proposes training a classifier on the organisation's own labelled ticket history. The project manager is asked to decide how the options should be compared.

  1. AChoose the general-purpose model, as it has seen far more text than the organisation holds
  2. BChoose the in-house classifier, as a model built on the organisation's own tickets always fits better
  3. CCombine both approaches so that the strengths of each one are retained
  4. DEvaluate both approaches against the same held-out tickets and the same agreed success measure
Key ideaCompeting approaches are chosen on evidence against the same task, not on the reputation of the method.
ABroad pretraining is an advantage on general language, but the task is this organisation's own categories. Whether that advantage carries over is exactly what the comparison is meant to establish.
BMatching the organisation's categories may help, but it does not guarantee better performance. A small or inconsistent ticket history can still produce a weaker classifier than an adapted general model.
CCombining methods may be worth exploring later, but it adds cost and complexity before either approach has been shown to work. The decision in front of the project manager is how to compare them.
DRunning both approaches on identical data and one agreed measure makes the comparison meaningful. Anything else compares the methods' reputations rather than their performance on this task.
CPMAI-D4-007 Error cost and decision thresholdsMEDIUM Answer: C

A team proposes a cut-off that would send roughly four hundred cases a day for manual review. The review team consists of six people who can each assess about twenty cases a day. The team argues the cut-off is correct because it maximises the number of genuine cases caught. What should the project manager conclude?

  1. AThe cut-off is correct, since catching the greatest number of genuine cases is the model's purpose
  2. BThe review team should be expanded until it can assess every case the model flags
  3. CA cut-off producing more cases than can be reviewed will leave most of them unactioned
  4. DThe cases should be reviewed in the order they arrive so none of them waits unduly long
Key ideaA cut-off that exceeds the capacity to act on its output delivers less than one that fits within it.
AThe purpose is acting on genuine cases, not flagging them. Flags that no one can assess do not produce the intended outcome.
BExpanding the team may be one option to put to the sponsor. It is a resourcing proposal rather than the conclusion to draw about the cut-off as it stands.
CAround a hundred and twenty cases a day can be assessed. The rest queue or lapse, so the genuine cases in that remainder are caught on paper but not in practice.
DArrival order distributes the delay but does not create capacity. The same proportion of cases still goes unassessed.
CPMAI-D4-008 Overfitting, generalisation and robustnessEASY Answer: B

A team reports that its model classifies ninety-six per cent of training records correctly but only sixty-one per cent of the held-out test records. The team is pleased with the training figure. What does the gap between the two indicate?

  1. AThe test set must contain records that are harder than those used for training
  2. BThe model has learned the training records rather than the underlying pattern
  3. CThe model needs more training rounds to bring the test figure up to the training figure
  4. DThe training figure is the one to report, since it rests on far more records than the test figure
Key ideaA large gap between training and held-out performance is evidence the model has fitted its training set.
AA random split gives no reason to expect the test records to be systematically harder than the training records. A gap of this size is more consistent with the model than with an unlucky draw.
BDetail specific to the training records does not recur in new data. The model reproduces what it memorised, which is why performance falls away on records it has not seen.
CContinuing to train does not by itself establish that held-out performance will catch up. Where the model is already fitting training detail, further training can widen the gap instead.
DSample size does not make a training score informative. It measures material the model has already seen.
CPMAI-D4-009 Data leakageMEDIUM Answer: A

A team reports unusually strong test performance on a document classification model. Investigation shows the source system had recorded many documents twice, and the random split placed copies of the same document in both the training and the test set. What does this mean for the reported score?

  1. AThe score partly measures documents the model already saw during training
  2. BThe score is valid, because duplicate documents are genuine records that occur in the real data
  3. CThe score is too low, because duplicated documents take up places that other documents could have filled
  4. DThe duplicates should be left in place and the model retrained with a smaller training set
Key ideaA test record the model has already seen in training measures recall of that record, not generalisation.
AFor every duplicated document the model is being asked about material it has already learned. Those cases inflate the score without saying anything about unseen documents.
BDuplicates may well occur in the source system, but that does not make them valid test cases here. The test set must contain material the model has not been trained on.
CThe direction is wrong. Seeing the same document in training makes the test easier, so the score is inflated rather than depressed.
DShrinking the training set does not separate the copies. The duplicates would still straddle the split and the score would still be inflated.
CPMAI-D4-010 Feature engineering and preparationMEDIUM Answer: C

A team encodes two categorical fields for a pricing model. One records a service tier as standard, priority or express; the other records the handling depot, of which there are nine with no inherent ordering. The team applies the same numeric encoding to both. What problem does this create?

  1. AThe service tier field is given an order that its three levels do not carry
  2. BNine depots is too many distinct values for a categorical field to be usable
  3. CThe depot field is given an order and a spacing that it does not actually have
  4. DBoth fields need numbers, so one consistent encoding across them is correct
Key ideaEncoding an unordered category as a number asserts an ordering and spacing the data does not have.
AThe tiers do carry a natural progression from standard through priority to express, so a numeric encoding is defensible there. The unordered field is the one that is misrepresented.
BNine categories is a modest number and presents no particular difficulty. The issue is the kind of encoding applied, not the count of categories.
CNumbering the depots implies that depot seven sits between six and eight in some meaningful sense. No such relationship exists, so the model is fed a structure that is not real.
DConsistency is not the goal. The encoding has to match the nature of each field, and applying one scheme to fields of different kinds is what causes the problem.
CPMAI-D4-011 Model evaluation metricsMEDIUM Answer: A

A team is predicting how many days a repair will take. It reports that the model is correct eighty-two per cent of the time. The project manager notes that the quantity being predicted is a number of days rather than a category. What is wrong with the way performance has been reported?

  1. AA numeric prediction should be judged by the size of its error, not by exact matches
  2. BEighty-two per cent is too low a figure to support deploying a repair duration model
  3. CThe model should predict a range of days rather than a single number of days
  4. DAccuracy should have been reported separately for each type of repair in the dataset
Key ideaA prediction of a quantity is judged by how far it lands from the truth, not by whether it is exactly right.
ATreating a predicted duration as right or wrong throws away how wrong it was. A forecast one day out and one thirty days out are very different, and the reported figure cannot tell them apart.
BWhether a level of performance is adequate depends on the use. The reporting problem stands regardless of whether the number is high or low.
CPredicting an interval can be genuinely useful for planning. It is a change to what the model outputs and does not fix how the current output is being scored.
DBreaking results down by repair type is worthwhile analysis. It does not address the use of an exact-match measure for a numeric prediction.
CPMAI-D4-012 Training data strategy and validation designMEDIUM Answer: C

A team proposes generating synthetic records to enlarge a small training set for a credit risk model, arguing that the real data will take another two quarters to accumulate. The sponsor is willing to fund the tooling. What should the project manager require the team to establish?

  1. AThat synthetic records can be produced faster than real records are collected
  2. BThat synthetic records are stored separately from real records in the warehouse
  3. CThat synthetic records preserve the relationships and variation relevant to the prediction task
  4. DThat synthetic records are generated by a vendor tool rather than in-house code
Key ideaSynthetic data is only useful if it carries the structure the model needs to learn.
AGeneration speed is an advantage of synthesis and is not the binding constraint here. Producing unhelpful records quickly does not advance the model.
BKeeping synthetic and real records distinguishable is sound data management and supports later evaluation. Storage separation does not make the synthetic data fit for training.
CThe value of synthetic records depends on whether they preserve the relationships and variation relevant to the prediction task. Their usefulness should then be checked against real held-out data.
DVendor tooling may bring maturity and validation features worth having. Provenance of the generator is not what determines whether the output is faithful.
CPMAI-D4-013 Bias, fairness and evaluation transparencyMEDIUM Answer: D

An agreed requirement for a maintenance prioritisation model states that a supervisor must be able to see why a job was ranked where it was. At the evaluation review the team presents accuracy figures and a ranked list, but the model produces no case-level reasoning. What is missing before the model can pass evaluation?

  1. AA training session explaining how the model was built and which algorithm it uses
  2. BA higher overall accuracy figure, so supervisors have more reason to trust the ranking
  3. CA process allowing supervisors to override any recommendation they disagree with
  4. DEvidence that the model can produce the case-level reasoning the requirement specifies
Key ideaA model is evaluated against every agreed requirement, not only against its performance figures.
AExplaining the method in general does not demonstrate that the model can give a reason for an individual ranking, which is what the agreed requirement specifies.
BA higher figure speaks to how often the ranking is right, not to whether a supervisor can see why a job was ranked where it was. The requirement would remain unevidenced.
CAn override route lets a supervisor reject a ranking without understanding it. It does not supply the case-level reasoning the requirement calls for.
DThe requirement forms part of what the model is evaluated against. Performance figures do not show it is met, so until case-level reasoning is demonstrated the model has not passed evaluation.

  1. AImprovement will continue at a steady rate provided the team's resourcing is maintained at its current level
  2. BFurther gains are uncertain in size and timing, so they cannot be scheduled as fixed increments

CPMAI-D4-015 Model approach and algorithm selectionMEDIUM Answer: D

A team is beginning model development for a demand forecasting problem and proposes moving straight to a complex architecture, on the grounds that the business expects a sophisticated solution. The project manager asks what the results will be compared against. What should the project manager require first?

  1. AA sponsor commitment to fund the complex architecture through to deployment
  2. BA written statement of the intended architecture and the libraries it depends on
  3. CAn estimate of the computing time the architecture will need during training
  4. DA simple baseline, so any gain from the complex approach can be measured against it
Key ideaWithout a simple reference point, a complex model's score cannot be shown to be worth its cost.
AFunding certainty helps planning but says nothing about whether the complex approach performs better than a simple one. The comparison question the project manager raised would remain unanswered.

CPMAI-D4-016 Error cost and decision thresholdsMEDIUM Answer: B,D

Before a fraud detection model goes live, the project manager wants the cut-off set deliberately rather than by default. The team asks what information is needed from the business to make that decision. Select two.

  1. AThe algorithm the team used to produce the fraud scores
  2. BThe relative cost of a missed fraud and a wrongly flagged transaction
  3. CThe share of transactions that were fraudulent in each of the last three years
  4. DThe number of flagged cases the review team can handle in a day
  5. EThe total number of features the model uses to generate each score
Key ideaSetting a cut-off requires knowing what each error costs and how much review capacity exists.
AThe method behind the scores does not determine where the cut-off belongs. The same cut-off question arises whatever algorithm produced them.
BThe cut-off balances the two errors, so their relative cost sets where the balance should fall. Without it the choice has no basis beyond convention.
CHistorical prevalence is useful background for interpreting the scores. It does not by itself say what balance of errors the business should accept.
DA cut-off that flags more cases than the team can review produces a backlog, and the unreviewed cases receive no action. Capacity puts a practical ceiling on the choice.
EFeature count describes the model's construction and has no bearing on where the decision boundary should sit.
CPMAI-D4-017 Overfitting, generalisation and robustnessMEDIUM Answer: C

A team's model scores poorly on both the training data and the held-out data, at levels close to what a simple guess would achieve. Training has been run to convergence and the usual optimisation settings have been tried without effect. The team proposes collecting substantially more records of the same kind. What should the project manager consider first?

  1. AWhether the held-out set is large enough for the reported score to be stable
  2. BWhether the team has trained for long enough for performance to settle
  3. CWhether the model and its features can represent the relationship at all
  4. DWhether the additional records can be collected within the schedule the sponsor agreed
Key ideaWhere a converged model underperforms on its own training data, capacity or features are the constraint.
ATest set size affects how precisely performance is measured. It does not explain a model that also fails on its training data.
BThe stem establishes that training has been run to convergence, so duration has already been ruled out as the explanation.
CWith training converged, weak performance on the records the model was fitted to points at the model or the feature representation rather than the amount of data. More records of the same kind are unlikely to address that.
DFeasibility of collection matters only once more data is established as the remedy, which it has not been.
CPMAI-D4-018 Data leakageHARD Answer: A

A team is building a model to predict readmission from patient records. Many patients appear several times in the dataset, once per admission. The evaluation is required to estimate how the model will perform for patients not represented in the training data. The team splits the records at random, so a given patient's admissions can fall on both sides of the split. What risk does this create?

  1. AThe model can recognise individual patients rather than learn the pattern behind readmission
  2. BPatients with several admissions will be weighted more heavily than patients with only one
  3. CThe test set will contain fewer distinct patients than the training set, making it less representative
  4. DAdmissions for the same patient may have been recorded in different formats over time
Key ideaWhere the objective is performance on unseen entities, the split must separate entities rather than records.
AAdmissions for one patient share many characteristics. With the same patient on both sides, the model can succeed by matching a familiar patient, which is precisely what the stated evaluation objective excludes.
BRepeated records do give frequent patients more influence during training, which is worth managing. It is a separate issue from the split placing one patient on both sides.
CThe counts follow from the proportions of the split and are not the problem. The problem is that the same patient appears in both sets.
DInconsistent recording is a data quality matter to be checked. It is unrelated to how the split was drawn.
CPMAI-D4-019 Feature engineering and preparationEASY Answer: B

A team is preparing a feature set in which one field records an age in years and another records an annual amount that runs into the hundreds of thousands. The team plans to use a method that is sensitive to the relative scale of its inputs. What preparation step does this call for?

  1. ARemoving the larger-valued field, since it would otherwise overwhelm the other
  2. BPlacing both fields on a comparable scale before training begins
  3. CRounding the larger values so both fields hold a similar number of digits
  4. DRecording both fields as text so the method does not read them as quantities
Key ideaScale-sensitive methods treat a large-valued field as more important simply because its numbers are bigger.
ADropping the field discards information that may be genuinely predictive. The problem is the difference in scale, which rescaling addresses without losing the field.
BWhere a method measures distances or weights inputs by magnitude, the field with larger numbers dominates. Rescaling puts the fields on comparable footing so each contributes on its merits.
CRounding reduces precision without reliably equalising scale, and it destroys detail in the larger field. It is not a substitute for a proper rescaling step.
DStoring numbers as text prevents the method from using their magnitude at all, which removes real information. The aim is comparable scale, not the loss of numeric meaning.
CPMAI-D4-020 Model evaluation metricsEASY Answer: B

A team presents a confusion matrix for a classifier that identifies faulty parts. The project manager wants to know how often a part the model flagged as faulty actually turned out to be faulty, because every flagged part is pulled off the line for inspection. Which measure answers that question?

  1. ARecall, the share of genuinely faulty parts that the model managed to flag
  2. BPrecision, the share of flagged parts that were genuinely faulty
  3. COverall accuracy, the share of all parts the model classified correctly
  4. DSpecificity, the share of sound parts that the model correctly left unflagged
Key ideaPrecision describes how often a positive prediction is correct, which matters when every false positive triggers unnecessary inspection.
ARecall answers the complementary question of how many faults were caught. It says nothing about how many flagged parts turn out to be sound.
BPrecision looks only at the cases the model flagged and asks how many were right. That directly answers how often a flagged part actually proves faulty; combined with flagged volume, it can also help quantify inspection effort spent on sound parts.
CAccuracy pools flagged and unflagged parts together. A model can score well on it while most of its flags are wrong, particularly when faults are uncommon.
DSpecificity describes behaviour on sound parts across the whole line. It does not isolate the flagged group that inspection actually acts on.
CPMAI-D4-021 Training data strategy and validation designEASY Answer: A

A team splits its data into a training set, a validation set and a test set. A stakeholder asks why two separate held-out sets are needed when one would be simpler to manage. What is the reason for keeping them separate?

  1. AThe validation set guides development choices, so an untouched test set gives the final independent estimate
  2. BThe validation set checks the training data quality and the test set checks the model
  3. CTwo held-out sets allow the team to report two accuracy figures to the stakeholders
  4. DThe validation set is used during training and the test set after the model is deployed
Key ideaA set used to make development choices can no longer provide an independent estimate of performance.
AEach time the validation set informs a decision, the model is shaped a little to suit it. A set that played no part in those decisions provides the independent estimate of behaviour on new data.
BChecking data quality is a separate purpose from the roles of the validation and test sets. The validation set guides development choices, while the untouched test set provides the final independent estimate.
CReporting two numbers is a consequence, not a purpose. The reason for the separation is that only one of them is an independent estimate.
DThe test set is used before deployment to support the go-live decision. Holding it until after deployment would leave that decision unevidenced.

CPMAI-D4-025 Error cost and decision thresholdsMEDIUM Answer: D

A team lowers the score at which a collections model refers an account for intervention, so that more at-risk accounts are caught. The project manager is asked what else will change as a result. What should be expected?

  1. AThe model will become more accurate on both the at-risk and the sound accounts
  2. BThe proportion of referred accounts that genuinely need intervention will rise
  3. CThe model will need to be retrained before the change to the cut-off takes effect
  4. DMore accounts in total will be referred for intervention

The project manager notes that a substantial share of incoming records arrive with one or more fields absent, and that the selected algorithm produces no output at all for a record with a missing field. What should the project manager require?

  1. AThat the records with absent fields be excluded from scoring once the model is in use
  2. BThat candidates be compared on records that include the absent fields the model will receive
  3. CThat the selected algorithm be retrained on a larger sample so it tolerates absent fields
  4. DThat the absent fields be dropped from the feature set so every record can be scored
Key ideaA model is selectable only if it can produce an output for the records it will actually be given.
AExcluding those records leaves a substantial share of cases without a prediction, which is the outcome the model was meant to provide. It converts a modelling gap into a coverage gap.
BThe selection compared candidates on records that do not resemble what will arrive. Comparing them on records carrying the same absences establishes which candidate can actually serve the incoming data.
CMore training records do not give an algorithm the ability to accept an input it cannot process. The limitation is in what the method accepts, not in how much it has seen.
DDropping every field that is sometimes absent can remove much of the model's predictive information, and it addresses the input shape rather than which candidate suits the data.
CPMAI-D4-052 Error cost and decision thresholdsHARD Answer: D

A model screens medical images for a condition that is treatable when caught early and serious when missed. Flagged images go to a specialist for a second look. The team has tuned the model to the cut-off that maximises overall accuracy. What should the project manager challenge?

  1. AThat the cut-off should have been chosen before the model was trained rather than after
  2. BThat accuracy cannot be calculated at all for a model that produces a continuous score
  3. CThat the specialist review step should be removed so the model's decisions stand on their own
  4. DThat the two errors are being treated as equally costly when they clearly are not
Key ideaMaximising accuracy treats each misclassification equally, which can be inappropriate when the two errors differ in consequence.
AThe cut-off is normally set once scores exist, and doing so afterwards is standard. The objection is which criterion was used to set it.
BAccuracy is readily calculated once a cut-off converts scores into decisions. The measure is available; it is simply the wrong one to optimise here.
CRemoving human review would raise the cost of every error rather than reduce it. It makes the underlying problem worse.
DMaximising accuracy weighs a missed condition the same as an unnecessary specialist review. The scenario establishes that a miss risks serious harm while a false flag costs a review, so the cut-off should reflect that difference.
CPMAI-D4-053 Overfitting, generalisation and robustnessMEDIUM Answer: C

A model has been evaluated on held-out records drawn from the twelve sites where it was trained. The planned rollout covers those twelve sites and nine further sites that contributed no data. The team presents the held-out score as evidence the model is ready. What should the project manager require before the rollout is approved?

  1. AA larger held-out set drawn from the twelve sites, so the reported score is more precise
  2. BConfirmation that the nine further sites use the same recording systems as the original twelve
  3. CEvidence of performance at sites that contributed no data, before those sites are included
  4. DA commitment to re-evaluate the model at the nine further sites once the rollout is complete
Key ideaEvaluation evidence covers the population it was drawn from, not the wider population of a rollout.
AA larger sample from the same twelve sites sharpens an estimate for those sites. It says nothing about the nine that contributed no data.
BMatching recording systems would remove one source of difference and is worth confirming. Sites can still differ in case mix and local practice, so it does not establish performance at the new sites.
CThe held-out score describes the twelve sites it was drawn from. Extending the rollout to sites outside that population needs evidence for those sites, whether from a pilot, a held-out site or comparable data.
DRe-evaluating after the rollout means the nine sites operate on unevidenced performance in the interim, which is what the approval decision is meant to prevent.

A project manager reviews the feature set assembled for a shipping cost model and finds two numeric fields, one recording package weight in pounds and the other recording the same weight in kilograms, so that each is an exact conversion of the other. What is the practical consequence of keeping both?

  1. AThe pair will cause the training process to fail with a conversion error
  2. BThe pair will double the storage the feature set requires in the warehouse
  3. CThe pair will prevent the dataset from being split into training and test sets
  4. DThe pair adds no information and can complicate interpretation of the model
Key ideaTwo expressions of one measurement are one feature written twice.
ATraining runs perfectly well with correlated features. No conversion error arises from having both units present.
BOne extra numeric column is a negligible storage cost. Efficiency is not the meaningful consequence.
CSplitting is unaffected by feature redundancy. The split operates on rows, not on the relationship between columns.
DThe second field carries nothing the first does not. Redundant representations can also complicate or divide feature-attribution measures, depending on the model and the interpretation method used.
CPMAI-D4-055 Model evaluation metricsHARD Answer: B

Two models are compared for a triage tool that will rank incoming cases so reviewers work through the highest-risk first. Model A scores higher on accuracy at the default cut-off; model B separates high-risk from low-risk cases better across all cut-offs. The cut-off has not yet been fixed. Which model should be preferred?

  1. AModel A, because accuracy at the default cut-off is the measure the stakeholders will recognise
  2. BModel B, because the tool depends on ranking and the cut-off can still be chosen
  3. CModel A, because a model that is more accurate at one cut-off will be more accurate at any other
  4. DNeither, until both models have been retrained on the same data with the same cut-off applied
Key ideaWhere the operating point is not yet fixed, ranking quality matters more than accuracy at one cut-off.
AFamiliarity is a reason to explain a measure carefully, not to select on it. The default cut-off is arbitrary and will not be the one the tool uses.
BThe reviewers work down an ordered list, so what matters is whether risky cases sit above safe ones. A model that ranks better will outperform once the cut-off is set appropriately.
CThis does not follow. Two models can cross, so ordering at one cut-off does not determine the ordering elsewhere.
DThe models are already being compared on the same data. Fixing a single cut-off first would discard the ranking evidence that distinguishes them.
CPMAI-D4-056 Training data strategy and validation designMEDIUM Answer: D

A team has around three hundred labelled records for a specialised classification problem and no prospect of obtaining more. Setting aside a fifth of them for testing leaves the model with little to learn from, and the resulting score swings widely depending on which records are held out. What approach addresses this?

  1. AReduce the held-out portion to a twentieth so more records remain available for training
  2. BRepeat the single split several times and report whichever result is closest to the average
  3. CTrain on all three hundred records and report the accuracy measured on those same records
  4. DCross-validation, rotating the held-out portion across several rounds and averaging the results
Key ideaRotating which records are held out uses every record for both training and testing across repeated rounds.
AA smaller test set leaves more for training but makes the score even less stable, because it now rests on fifteen records. This worsens the swing rather than addressing it.
BSelecting a result because it looks typical discards the evidence of variation. The spread is information about reliability, not noise to be filtered out.
CA score measured on the training records reflects what the model has memorised. It gives no indication of behaviour on records the model has not seen.
DEvery record serves as training data in some rounds and as test data in others. The averaged score rests on all the data and is far less sensitive to one unlucky split.
CPMAI-D4-057 Bias, fairness and evaluation transparencyMEDIUM Answer: A

A recruitment screening model is reported at eighty-four per cent accuracy overall. The project manager asks for results broken down by applicant group and finds the model rejects qualified applicants far more often in one group than in others. The team says the overall figure meets the agreed target. What should the project manager conclude?

  1. AMeeting an aggregate target does not establish that the model performs acceptably for each group
  2. BThe breakdown is not comparable, because the groups contain different numbers of applicants
  3. CThe difference is acceptable provided the model was not given the group as an input
  4. DThe model should be retrained until every group reaches exactly the same error rate
Key ideaOne aggregate figure cannot show whether a model's errors fall evenly across the people it affects.
AAn overall figure averages across groups, so strong performance on large groups can conceal poor performance on smaller ones. The agreed target does not test that distribution.
BError rates are proportions, so they remain comparable across groups of different sizes. Small groups give less precise estimates, which is a reason to check precision rather than dismiss the finding.
CExcluding an attribute does not prevent a model from producing different error rates across groups, as other fields can carry the same information.
DExact equality is not automatically the appropriate fairness criterion. The criterion has to be defined for this use, and the observed disparity investigated against it.

Before evaluation begins, the project manager wants the criteria for proceeding to deployment agreed in advance rather than debated once results are in. The team asks what those criteria should specify. Select two.

  1. AThe algorithm the team intends to use to build the model
  2. BThe minimum performance the model must reach on the measure that matters to the business
  3. CThe number of experiments the team expects to run before reaching the target
  4. DThe date on which the deployment decision will be taken
  5. EThe data the model must reach that level on
Key ideaCriteria fixed before results are seen prevent the standard being adjusted to fit the outcome.
AFixing the method in advance constrains the work without making the decision testable. The criteria concern the result, not the route to it.
BA stated level on an agreed measure is what makes the result testable. Without it, any outcome can be argued as sufficient once it is known.
CExperiment count is a planning estimate. It says nothing about whether the resulting model is good enough to deploy.
DA date sets the timetable for the decision but supplies no standard against which to take it.
EA level is meaningless without the data it applies to. Naming the evaluation set in advance prevents a favourable set being chosen afterwards.
CPMAI-D4-059 Feature engineering and preparationMEDIUM Answer: D

A team is preparing features for a model that predicts insurance claim handling time. Profiling shows the handling-office code field contains several thousand distinct values, and that the large majority of those codes appear in only a few claims each. What issue does this raise for feature preparation?

  1. AThe field will consume substantially more storage than all other features combined
  2. BThe field cannot be used at all because models accept only numeric input values
  3. CThe field will need sorting into alphabetical order before it can serve as a feature
  4. DSparse categories make category-specific patterns hard to estimate reliably
Key ideaHigh cardinality spreads the data thin, leaving most categories with almost no examples.
AStorage for one identifier column is negligible. Cost is not what makes high cardinality difficult to work with.
BCategorical fields can be encoded into numeric representations. The need to encode applies to every category field, not uniquely to this one.
CSorting affects presentation and some join strategies. It has no bearing on how a model consumes a categorical feature.
DWith several thousand offices, most appear in only a handful of claims, leaving little evidence for category-specific behaviour. This needs deliberate treatment such as grouping, encoding choices or regularisation rather than naive use of the raw codes.
CPMAI-D4-060 Model evaluation metricsHARD Answer: D

A team is building an intrusion detection model on network logs in which roughly 0.1% of events are genuine attacks. An early model is reported to the project manager as achieving 99.9% accuracy on the held-out test set, and the team proposes moving to the next phase. What should the project manager conclude about the reported performance?

  1. AThe dataset is of unusually high quality given the accuracy achieved
  2. BThe dataset needs additional features to push accuracy above 99.9%
  3. CThe dataset should be split differently to raise the measured accuracy
  4. DThe severe class imbalance makes overall accuracy uninformative, so performance on the attack class must be examined separately
Key ideaAt a base rate this extreme, predicting the majority class alone scores near-perfect accuracy.
AReading the figure as evidence of data quality is the trap the imbalance sets. The number reflects the class distribution rather than the dataset or the model.
BChasing a higher number on a metric that cannot discriminate here compounds the error. More features do not make overall accuracy informative about the attack class.
CChanging the split shifts which records land where without altering the base rate. The metric would remain equally uninformative.
DA model labelling every event as normal reaches 99.9% while catching no intrusions. Overall accuracy alone is therefore uninformative about attack-class detection at this level of imbalance, so performance on the attack class has to be measured in its own right.
